# Instruções para jogar localmente #

### ⚠  Necessário Python instalado ###
### ⚠  Verifique se a porta 8000 do seu sistema operacional está livre ### 

- Baixe o projeto compactado 
- Extraia todos os arquivos em um diretório
- Abra a pasta do projeto e execute o arquivo "server.bat", irá abrir um prompt de comando (Não feche essa janela) 
- Abra o seu navegador de preferência e insira (http://localhost:8000/) 
- Espere o carregamento e jogue 
- Se quiser parar de jogar, feche o prompt de comando
